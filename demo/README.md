# demo

**YouTube: https://youtu.be/c1amhZA4Kro**

`REEVL_for_Pleos_demo.mp4` (2분 33초, 1920×1080) — 휴대폰(리블 웹)과 차(REEVL for Pleos, Pleos Connect Emulator 2.1.0)의 **실제 화면 녹화**를 핵심 기능 9장면으로 편집했습니다(2026-11-14).

| # | 장면 | 화면 |
|---|---|---|
| 1 | 운전 중(D · 30km/h) Gleo로 "오른쪽 단지 뭐야? / 얼마야? / 앞에 있는 단지는? / 왼쪽에 천 세대 넘는 곳? / 이 동네는?" | Gleo 대화 + 차 |
| 2 | 지나가는 단지, 왼쪽 · 오른쪽 · 지나옴 | 차 |
| 3 | 말하듯 검색 "1,000세대 넘는 곳" | 차 |
| 4 | 정차하면 단지 상세 | 차 |
| 5 | 휴대폰에서 짠 임장 계획 → 차 '오늘 방문'·동선 지도 | 휴대폰 + 차 |
| 6 | 지나가다 본 단지를 계획 중간에 끼워 넣기 | 차 |
| 7 | 길 안내는 Pleos NaviHelper로 기본 내비에 | 차 |
| 8 | 차에서 저장 → 휴대폰 리블에도 | 휴대폰 + 차 |
| 9 | 시작은 QR 한 번 (계정 연결) | 휴대폰 + 차 |

- 단지·거래 값은 리블 실데이터, 차량 위치는 에뮬레이터 좌표(서울 종로구), 계정은 로컬 서버의 테스트 계정(debug 빌드)입니다.
- 편집: 대기 시간을 1.1~1.4배로 줄였고, 누르는 곳은 손가락 점과 파란 고리로, 주요 조작은 그 위치로 확대해 보여 줍니다. 화면 내용은 바꾸지 않았습니다.
- 1번 Gleo 장면: 에뮬레이터에 음성 입력 경로가 없어, Gleo와 같은 형식의 호출(Intent)을 앱에 보내고 앱이 돌려준 콜백(Gleo가 수신)을 왼쪽 대화로 표시했습니다. 질문 문장은 그 호출을 사람이 말한 문장으로 적은 것이며, 실제 음성 발화 장면이 아닙니다.
