# demo

`REEVL_for_Pleos_demo.mp4` (4분 16초, 1920×1080) — 휴대폰(리블 웹)과 차(REEVL for Pleos, Pleos Connect Emulator 2.1.0)의 **실제 화면 녹화**를 나란히 편집했습니다(2026-11-14).

| # | 장면 | 화면 |
|---|---|---|
| 01 | 계정 연결 — 차 QR → 휴대폰에서 같은 숫자 확인 → 연결 | 휴대폰 + 차 |
| 02 | 휴대폰에서 만든 임장 계획이 차 '오늘 방문'·동선 지도로 | 휴대폰 + 차 |
| 03 | 순서 정리 (1.2km → 750m 미리 보기 → 적용) | 차 |
| 04 | 주변 단지 · 왼쪽 / 오른쪽 / 지나옴 | 차 |
| 05 | 지금 있는 동네 (요약 · 히트맵 · 뉴스) | 차 |
| 06 | AI 검색 "1,000세대 넘는 곳" | 차 |
| 07 | 단지 상세 6개 탭 | 차 |
| 08 | 비교 | 차 |
| 09 | 휴대폰으로 넘기기 (QR) | 휴대폰 + 차 |
| 10 | 현장에서 끼워 넣기 (1 다음 / 2 다음 / 맨 끝) | 차 |
| 11 | 저장 → 휴대폰 리블 계정에도 | 휴대폰 + 차 |
| 12 | 길 안내 — NaviHelper로 기본 내비 | 차 |
| 13 | 주행 중 화면 잠금 + Gleo 함수 4번 호출·응답 | Gleo 대화 + 차 |
| 14 | 정차하면 이어서 · 지나온 길 기억 끄기/켜기 | 차 |

- 단지·거래 값은 리블 실데이터, 차량 위치는 에뮬레이터 좌표(서울 종로구), 계정은 로컬 서버의 테스트 계정(debug 빌드)입니다.
- 장면 사이 대기 시간은 1.15~1.35배로 줄였습니다.
- 13번 Gleo 장면: 에뮬레이터에 음성 입력 경로가 없어, Gleo와 같은 형식의 호출(Intent)을 보내고 Gleo(ai.umos.ambientai)가 받은 콜백을 왼쪽 대화로 표시했습니다. 실제 음성 발화 장면이 아닙니다.
