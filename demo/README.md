# demo

`REEVL_for_Pleos_demo.mp4` (약 2분, 1280×720) — Pleos Connect Emulator 2.1.0의 실제 앱 화면 녹화(2026-11-14).

- 단지·거래 값은 리블 실데이터, 차량 위치는 에뮬레이터 좌표(서울 종로구), 계정은 로컬 개발 서버의 테스트 계정(debug 빌드).
- 순서: 오늘 방문 → 주변 단지 → AI 검색("1,000세대 넘는 곳", 왼쪽/오른쪽) → 단지 상세 → 저장 → 방문 추가 → NaviHelper 길 안내 → 주행(D) 잠금 → Gleo 함수 호출·응답 → 정차 → 저장 목록.
- Gleo 부분은 adb로 Gleo와 같은 형식의 호출(Intent)을 보내고, Gleo(ai.umos.ambientai)가 받은 콜백을 로그에서 읽어 자막으로 표시했습니다. 실제 음성 발화 장면이 아닙니다(에뮬레이터에 음성 입력 경로 없음).
